# TaskFlow backend

> Focused on learning

TaskFlow is a learning-oriented TypeScript and Express REST API for team task management. It demonstrates MongoDB/Mongoose persistence, JWT authentication, workspace authorization, email providers, BullMQ jobs, Redis, logging, and Swagger.

Read the [backend docs](docs/index.md) for setup instructions, architecture, API usage, learning notes, known development findings, troubleshooting, and future work.

Swagger UI is served at `/docs` when the API is running.
